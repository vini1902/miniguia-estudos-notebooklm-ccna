# miniguia-estudos-notebooklm-ccna
Miniguia de estudos NotebookLM para CCNA - Curso Dio

Contexto e Objetivos:
Escolhi o assunto CCNA - Cisco pois estou em estudos de redes de computadores e quis me aprofundar no assunto, e caso eu sinta um interesse maior já quero iniciar pela base da certificação do maior vendor de equipamentos de redes empresariais.

Curadoria de Fontes:
Coloquei 3 livros de guia da certificação da Cisco CCNA mais recentes.

Engenharia de Prompts e "Cicatrizes":
Como sou iniciante no assunto que coloquei, solicitei para informar os principais tópicos base para entender redes "Sou iniciante no assunto, quais são os principais tópicos base para este estudo?"

Depois solicitei um plano diário com duas horas por dia para estudos. "Monte um cronograma diário com 2 horas por dia para estudos".

E como exemplo, solicitei perguntas do primeiro tópico para usar de exemplos. "Gere perguntas do tópico Fundamentos de Redes (Network Fundamentals), com pelo menos 2 perguntas de cada assunto, para aprimorar os estudos.

Como é um estudo novo, não consegui extrair o máximo do NotebookLM, as respostas que obtive foram suficiente para estudar e aprofundar no assunto.

Miniguia de Estudo (Entrega Final):
Crie um resumo estruturado para um iniciante no assunto CCNA - Cisco, informando os principais tópicos base e os tópicos com maior peso no exame. 

Talvez eu tenha escolhido um assunto muito extenso, e o glossário está um pouco raso ainda. IPv4, IPv6, TCP/IP, Modelo OSI. 

Descobri que o NotebookLM pode criar um Quiz para verificar meu aprendizado e isto pode ser extremamente benéfico durante uma revisão de topicos.
